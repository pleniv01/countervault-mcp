Countervault public verification

Check an existing public receipt and compare a SHA-256 file fingerprint. Originals stay on your device. This read-only connector cannot access private accounts, save records, enable sharing or submit timestamps.

MCP endpoint: https://countervault-mcp-production.up.railway.app/mcp
Transport: Streamable HTTP · Authentication: none

A receipt link grants access to shared metadata. Supply only links you intend to check. A matching digest supports integrity; it does not establish truth, ownership, identity or legal notarization.

The demo input is explicitly synthetic and does not access a customer record.
